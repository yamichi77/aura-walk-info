# UI 仕様（2026-11-22 ユーザー承認済み）

HUD の見た目と振る舞いはこの文書に従う。ブラウザで開ける参照モックが [ui-mockup.html](ui-mockup.html) にある。
**配置・中央クリアゾーン・状態ごとの表示を変える場合は、ユーザーに確認してから変える。**

---

## 1. 前提

- AURA は光学シースルーの加法表示。**黒（#000000）は透明に見える。** パネルやカードに背景色を塗らない。描くのは文字と線だけ
- 角度の表記は次のとおり
  - 水平（yaw）: 「左」「右」と書く。正面が 0°
  - 垂直（pitch）: 「上」「下」と書く。目線の高さが 0°
  - Jetpack XR の `SubspaceModifier.rotate` の符号の向きはドキュメントに書かれていない。角度から offset と rotate への変換は `HudPlacement` に閉じ込め、符号は Phase 2 の角度ガイドで実測して決める
- パネルまでの距離は 1.5m（初期値）

## 2. 視野と禁止領域

```
                  左30°        左15°   0°   右15°        右30°
          上20° ┌──────────────┬──────────────┬──────────────┐
                │              │              │              │
                │              │   中央クリア  │              │
            0°  │- - - - - - - │ - ゾーン - - │- - - - - - - │ ← 目線
                │ ┌──────────┐ │  UI 禁止     │ ┌──────────┐ │
                │ │左クラスタ│ │  （上下とも）│ │ミニマップ│ │
                │ └──────────┘ │              │ └──────────┘ │
          下20° └──────────────┴──────────────┴──────────────┘
```

- 表示できる範囲: 約 水平61° × 垂直41°（左右30°、上下20°）
- **中央クリアゾーン: 左15°〜右15° の範囲には、上下とも何も描かない。** 例外はデバッグビルドの角度ガイドと、§9 の大きい地図とカウントダウン、§11 の空の方位帯（上14°〜19°）だけ
- 各クラスタはクリアゾーンの縁から 1° 以上離す（左クラスタの右端は左16°より外側、右クラスタの左端は右16°より外側）

## 3. レイアウト

### 3.1 左クラスタ: 現在時刻・距離・歩行時間・住所

- 基準点: **左22°、下8°**
- 範囲の目安: 水平は左29°〜左16°、垂直は下0°〜下16°（現在時刻の行を足したため、上端を下2°から下0°に上げた。2026-11-23 ユーザー承認）
- 中身は左揃えで、上から順に並べる

| 順 | 要素 | 例 | 文字サイズ（初期値） | 色 |
|---|---|---|---|---|
| 0 | 現在時刻（2026-11-23 ユーザー承認） | `14:32` | 16dp | `#B5D4F4` |
| 1 | 距離（数字 + 単位） | `1.24` `km` | 数字 32dp / 単位 16dp、太さ 500 | `#E0F7FF` |
| 2 | 歩行時間 | `歩行 18:42` | 16dp | `#E0F7FF` |
| 3 | 補助行（状態で中身が変わる。§5） | `経過 21:05 ・ 15'05"/km` | 14dp | `#9FE1CB` |
| 4 | 住所（1行または2行。§5） | `渋谷区神南1丁目` | 14dp | `#B5D4F4` |

- 現在時刻は24時間制の `H:mm`（例 `9:05`、`14:32`）。秒は出さない（毎秒変わるとちらつくため）。分が変わったときだけ書き換える
- 現在時刻は待機中・計測中・まとめ表示中のどれでも一番上に出す。測位なしでも色は変えない（GPS と関係ないため）。高速移動中と初回の注意文の表示中は、ほかの表示と同じく出さない
- 分が変わるときに量子演出（§10）は出さない。アプリの起動時の演出だけは、左クラスタのほかの行と一緒にかける

- 補助行が空のときは詰めて、住所を歩行時間のすぐ下に出す
- 見た目の大きさの目安（視角）: 距離の数字は約3.5°、ほかの文字は約1.5°。Phase 2 でエミュレータを見て dp 値を調整する

### 3.2 右クラスタ: ミニマップ

- 基準点: **右22°、下8°**（円の中心）
- 円の直径: 歩行中は **8°**、停止中は **12°**（右16°〜右28°）
- 描くもの
  - 円の枠: 1px、`#E0F7FF` の不透明度40%
  - 円の内側: 道路の線を描く。地面と背景は `#000000`（透明に見える）。POI（お店・施設など）と駅のアイコン（ピン）を出す。大きい地図では名前も出す（文字色 `#9FB8C8`）。道路名・地名などその他のラベルと線路は出さない（2026-11-23 ユーザー要望）
  - 現在地: 円の中心に矢印または小さな丸、`#7FDBFF`
- 地図の設定: Google Maps（maps-compose、Map ID なし、`MapStyleOptions` で JSON スタイル）、ズーム17〜18、ジェスチャは全部無効
- 地図は常に北が上（north-up）。現在地の矢印が進行方向を向く。進行方向が分からないときは矢印の代わりに小さな丸を出す（2026-11-23 ユーザー要望）
- ダークスタイルの目安: 地面 `#000000`、細い道路 `#3A3A3A`、太い道路 `#808080`、水域は暗い青

## 4. 表示形式

| 項目 | ルール | 例 |
|---|---|---|
| 距離 | 1km 未満は整数の m。1km 以上10km 未満は小数2桁の km。10km 以上は小数1桁の km | `850 m` / `1.24 km` / `12.3 km` |
| 歩行時間 | 1時間未満は `mm:ss`、1時間以上は `h:mm:ss`。先頭に「歩行」 | `歩行 18:42` / `歩行 1:02:03` |
| 経過時間 | 歩行時間と同じ形式。先頭に「経過」 | `経過 21:05` |
| 平均ペース | 分'秒"/km。距離が100m 未満のうちは出さない | `15'05"/km` |
| 住所（1行） | 市区町村 + 町名 + 丁目。都道府県と番地は省く。全角10文字を超えたら末尾を「…」で切る | `渋谷区神南1丁目` |
| 住所（2行） | 1行目は都道府県 + 市区町村、2行目は町名 + 丁目 | `東京都渋谷区` / `神南1丁目` |
| 住所（未取得） | 最初の取得が終わるまで | `住所取得中…` |
| 住所（取得失敗） | 一度も取れていない | `—` |

## 5. 状態ごとの表示

状態の判定条件は [PLAN.md](PLAN.md) §2.4 のとおり。複数当てはまるときの優先順位は **高速移動 > 測位なし > 停止中 > 歩行中**。

| | 歩行中 | 停止中 | 高速移動 | 測位なし |
|---|---|---|---|---|
| 左右クラスタ | 表示 | 表示 | **非表示** | 表示 |
| 不透明度 | 70% | 100% | — | 70% |
| 距離の色 | `#E0F7FF` | `#E0F7FF` | — | `#888780`（灰色） |
| 補助行 | なし | `経過 21:05 ・ 15'05"/km` | — | `GPS 測位中…` |
| 住所 | 1行 | 2行 | — | 1行（前回の値を `#888780` で） |
| ミニマップの直径 | 8° | 12° | — | 8° |
| 地図の道路と矢印 | 通常 | 通常 | — | 薄く（道路30%、矢印 `#888780`） |
| その他 | | | 左クラスタの位置に `高速移動中のため非表示` とだけ出す（14dp、不透明度85%） | 距離と歩行時間の加算は止める |

- **頭の回転中に HUD を消す機能は無効（2026-11-23 ユーザー判断）:** 装着しての確認で、消えるのが気になるとの判断で無効にした。回転中は追従が最大約5°遅れて、HUD の端が中央クリアゾーンに入ることがある（ユーザー了承）。頭の角速度はデバッグビルドのログにだけ残す
- 状態が変わるときは、不透明度と地図の大きさを約300ms かけて滑らかに変える。パッと切り替えない
- 通信できずに住所を更新できないときも、前回の値を `#888780` で出す

## 6. 追従

- 既定はヘッドロック: `Subspace(follow = FollowTarget.view(FollowMode.tight(TrackedDimensions.All)))`。頭を動かしても視界の同じ位置に出る
- 比較用に、ソフト追従（`FollowMode.soft`）と水平固定（yaw と位置だけ追従し、`gravityAligned()`）を開発用メニューから切り替えられるようにする。どれを最終にするかは Phase 4 の実地テストで決める

## 7. デバッグ用の角度ガイド（デバッグビルドのみ）

モックの「ガイド線」と同じものを HUD に重ねて出し、配置を目で確かめる。

- 表示できる範囲の枠（白の破線）
- 中央クリアゾーン（左15°〜右15°、琥珀色の破線と薄い塗り）
- 目線 0° の水平線
- 10° / 15° / 20° / 30° の目盛り

## 8. 参照モック（ui-mockup.html）の読み方

- ブラウザで開くと、上のボタンで4つの状態を切り替えられる
- 背景の街並みはイメージ用の絵で、実装しない
- 座標の対応: SVG の viewBox は 680×420。**1° = 8.5px**、正面 0° が x=340、目線 0° が y=200
  - 例: 左22° → x = 340 − 22×8.5 = 153、下8° → y = 200 + 8×8.5 = 268
- モックの文字サイズ（px）は見た目の目安であり、dp の値は §3 の表に従う

## 9. 歩行の開始・終了と大きい地図（2026-11-23 ユーザー承認）

大きい地図は中央クリアゾーン（§2）にかかる。ユーザーの判断で、歩行中も最大10秒まで開けることにした（停止中は30秒）。高速移動中は開けず、高速移動になったらすぐ閉じる

### 歩行の開始と終了

- **起動直後は「待機」。** 距離も時間も数えない（位置の取得・移動状態の判定・住所・地図は動かしておく。高速移動時の非表示も効かせる）
- 待機中の左クラスタ: 1行目に `タップで開始`（16dp、`#E0F7FF`）、その下に住所（1行、14dp、`#B5D4F4`）。距離と時間は出さない
- **開始:** 左クラスタをタップ → **3秒のカウントダウン**（`3` → `2` → `1`）。カウントダウン中に中央または左クラスタをタップするとキャンセルして待機に戻る。0 になったら新しい歩行を始める（距離・歩行時間・経過時間を 0 から）
- **終了:** 歩行中（計測中）に左クラスタをタップ → **3秒の終了カウントダウン**。中央または左クラスタをタップするとキャンセルして計測を続ける。0 になったら計測を止め、**まとめ**を出す
- **カウントダウンは視野の中央に大きく出す（2026-11-23 ユーザー要望）:** 開始・終了のカウントダウンの3秒間だけ、中央（左右 0°・上下 0°）に `開始` / `終了`、数字（高さ約4°）、`タップでキャンセル` を出す。中央クリアゾーン（§2）にかかるが、3秒間だけで、高速移動中は出さない。左クラスタには数字を出さない
  数字は量子っぽい演出で出す（2026-11-23 ユーザー要望）: 毎秒、点の雲が数字の形に収束し、ゆらいでから散る。3つの数字の輪郭が重なって見え、正しい数字だけが残る。数字の周りの細い円の上を光点が1秒で1周する。0 で波紋を1回出す。細い線と小さな点だけで描き、面は塗らない
- **まとめ:** 左クラスタに、1行目 `おつかれさま`（14dp、`#9FE1CB`）、距離（数字 32dp + 単位 16dp）、`歩行 mm:ss`、`経過 mm:ss ・ 平均ペース`（100m 未満ならペースなし）、`タップで新しく開始`（14dp、`#9FE1CB`）。まとめを表示している間にタップすると、開始のカウントダウンに入る
- カウントダウン・まとめの表示中も、高速移動なら `高速移動中のため非表示` が優先。頭の回転による非表示は T8 の定数に従う（今は無効）
- 計測中の表示は今までどおり（UI.md §5）
- フィールドログは、歩行を開始するたびに新しい CSV にする。待機中とまとめ表示中は記録しない
- 初回の注意文は今までどおり（起動直後に左クラスタの位置に出す。注意文の表示中のタップは、注意文を閉じるだけ）

### 大きい地図

- **開く:** 右下の地図（ミニマップ）をタップする。カウントダウン中は開けない
- **位置と大きさ:** 正面（左右 0°）、**下4°を中心に直径28°の円**（上10°〜下18°）。距離は他のパネルと同じ 1.5m。HudPlacement で配置する
- **中身:** ダークスタイル（ピンと名前は §3.2）・north-up（常に北が上）・中央の矢印または小さな丸（§3.2）。中央のマーカーは、ミニマップ（歩行中）と同じ見かけの大きさ。ズームは 16.5（広い範囲が見えるように）。円の枠は 1px 相当、`#E0F7FF` の 40%。不透明度は、歩行中 70%・停止中 100%（UI.md §5 と同じ）。開いている間、右下のミニマップは消す
- **自動で閉じる:**
  - 開いたときに停止中なら **30秒**、それ以外（歩行中・測位なし）なら **10秒** で閉じる
  - 開いている間に歩行中（または測位なし）になったら、閉じる時刻を「その時点から10秒後」と「今の閉じる時刻」の早い方にする
  - **高速移動になったら、すぐに閉じる。高速移動中は開けない**（タップしても開かない。`AuraInput` に `ignored-fast` と出す）
  - 頭の回転による非表示は、他のパネルと同じく T8 の定数に従う（今は無効）。消えている間もタイマーは進める
  - **目的地の入力中は閉じるまでのカウントを止める（2026-11-24 ユーザー要望）:** 聞いている・検索中・候補を表示中・経路の取得中は、自動で閉じない。入力が終わったら（候補を選んだ、やめた、エラーで地図に戻った）、停止中ならその時点から30秒、それ以外なら10秒で閉じる。ただし入力中に歩行中（または測位なし）になったら、その時点から10秒後に閉じる。高速移動ではすぐに閉じる（今までどおり）
  - 候補を選んだあとは、経路の取得中に地図が閉じても、取れたら案内を始める（2026-11-24 実機確認で、選んでも案内が始まらなかったため）
- **手動で閉じる:** 大きい地図をタップする、または**地図の外をタップ**したら閉じる。地図の外のタップを受けるため、大きい地図を開いている間だけ、視野全体を覆う透明（何も描かない）のパネルを後ろに置き、そのクリックで閉じる
- 開く・閉じるのアニメーションは約300ms のフェード
- **3D 表示のオプション（2026-11-23 ユーザー承認）:** `3D` / `2D` のボタン（下の「操作ボタン」）をつまむと切り替わる。選んだ方を覚えておき、次に開くときも使う。3D のときは地図を 60° 傾け、ズームは 18（2026-11-24 ユーザー要望で 17.5 から近づけた）、建物を立体で出す。建物は暗い灰色（`#262626`）で塗る。地図のスタイルでは建物と市街地の地面を分けられないので、市街地の地面も同じ灰色になる（黒で塗って輪郭だけにする案は、立体の建物に輪郭の指定が効かず真っ黒になったため、2026-11-24 実機確認でやめた。建物だけを塗り分けるには Map ID とクラウドのスタイルが要るが、立体の建物に縁取りはクラウドでもできない）。3D のときはお店などのアイコンと名前を出さず、駅だけを出す（2026-11-24 ユーザー要望。傾けると遠くまで映り、お店が大量に出るため）。3D でも北が上のまま。開ける条件・時間・位置・大きさは 2D と同じ
- **操作ボタン（2026-11-24 ユーザー承認）:** 大きい地図の操作（`3D` / `2D` と `目的地` / `ナビ終了`）は、地図の円の**外**、右側に置く。`目的地` は円の右上の外、`3D` / `2D` は円の右下の外。地図の円の中には操作の文字を重ねない（地図上の地名や表示と見分けがつかないため。2026-11-24 実機確認）。ボタンは大きい地図と一緒に出し入れする
  - 見た目（2026-11-24 ユーザー要望「今の量子表現と円の UI に合うもの」）: 細い円（視角 3° 程度、線 1px 相当、`#7FDBFF` の 70%）の中に、線で描いたアイコン（`目的地` はピン（地図アプリのピンに近い形: 丸い頭から先端へすぼまり、頭の中に小さな穴。2026-11-24 ユーザー要望）、切り替えは 3D なら立方体・2D なら平面、`ナビ終了` は ×）。円の下に小さく文字（14dp、`#E0F7FF`）。面は塗らない
  - 大きい地図が開くときは、ボタンの円も点が集まって現れ（§10）、光点が円の上を1回だけ回る。つまんだときは円から波紋を1回出す。それ以外の時間は動かさない（常に回り続けるような動きは付けない）

## 10. 量子演出（2026-11-23 ユーザー要望）

> 自分で操作したとき（歩行の開始・終了のまとめ・大きい地図の開閉）とアプリの起動時だけ、0.5 秒ほどの量子っぽい演出（点が集まって形になり、今の表示に落ち着く）を出す。数字の更新、移動状態の自動の切り替え、高速移動の非表示、初回の注意文には出さない。理由: 視界の端の動きは目を引くため、歩行中に勝手に HUD を動かさない

### 出す場面

| 場面 | 演出 |
|---|---|
| 歩行の開始（カウントダウンの波紋の直後） | 左クラスタの距離と時間が、点の雲から文字の形に集まって現れる。集まりきったら本物の文字に切り替わる |
| 終了のまとめ（終了のカウントダウンの直後） | 左クラスタの `おつかれさま` とまとめの数字が、同じように点から現れる |
| 大きい地図を開く | 点が集まって円（直径 28°）の輪郭になり、そこへ地図がフェードインする |
| 大きい地図を閉じる（タップでも自動でも） | 大きい地図の点が外へ散って消え、右下のミニマップが点から集まって現れる |
| アプリの起動（HUD が最初に出るとき1回だけ） | 左クラスタとミニマップが点から現れる。初回の注意文が出ているときは、注意文には演出をかけない |

### 出さない場面

- 距離・時間など、数字が更新されるとき（毎秒変わるため。目のちらつき、電池、発熱）
- 歩行中・停止中・測位なしの自動の切り替え（自分の操作ではないため。今の約300ms のフェードのまま）
- 高速移動で HUD を消すとき（安全のため即座に消す）。演出の途中で高速移動になったら、演出を打ち切って即座に消す
- 初回の注意文

## 11. 追加機能の表示の原則（2026-11-23 ユーザー承認）

空の方位帯・信号機の情報・ナビの表示の細かい見た目は、各タスク（T17b、T18b、T19）で案を作り、ユーザーの承認を得てからこの節に書き足す。ここには決まっている原則だけを書く。安全ルールの全体は [PLAN.md](PLAN.md) §2.5。

### 空の方位帯

- 視界の上端、**上14°〜19°の帯**にだけ描く。水平の向きは現実の方位（北が基準）に合わせ、高さは頭に固定する（上を向いても帯は視界の上端にある）
- 中央クリアゾーン（§2）に左右でかかるが、この帯だけは例外とする。信号機や標識は上3°〜15°あたりに見えることが多いので、帯はそれより上に置く
- 描くのは細い線と小さな印だけ。面は塗らない。不透明度は 50% 以下
- 出すのは、ナビ中（次の曲がり角と目的地の方向）と、信号機の情報を受けているとき（交差点の方向。表示方法が決まった場合）だけ
- 高速移動中、頭の追跡が途切れたとき、北の向きの推定誤差が 15° を超えるときは消す
- 設定でまとめてオフにできる
- 現実の空間に固定した地面の表示（地面の矢印や経路線）は作らない（2026-11-23 ユーザー判断。バッテリー消費と中央の視界のため）

### 信号機の情報

- 停止中で、交差点から 30m 以内のときだけ出す
- 受信が 1.5 秒途切れたら灰色（`#888780`）にし、3 秒で消す
- 青を目立たせない。「渡れます」などの判断の言葉は出さない

### ナビ

- 主な案内は、視界の端の立体の矢印と短い案内文（例 `30m先 右`）。位置は左右のクラスタの外側か上で、中央クリアゾーンにはかけない
- 3D の大きい地図に経路線と曲がり角を出す
