# T14: 現在時刻を左クラスタの一番上に出す（2026-11-23 ユーザー承認）

まず [README.md](README.md) の共通ルールを読むこと。T1〜T13 は main に入っている。追加機能の全体は [PLAN.md](../PLAN.md) §9。

## 目的

左クラスタの一番上に現在時刻を出す。仕様は [UI.md](../UI.md) §3.1（オーケストレーターが更新済み。**UI.md は変更しない**）。

## 決定事項（UI.md §3.1 の要点）

- 左クラスタの一番上（距離の上）に現在時刻を1行出す。16dp、`#B5D4F4`、太さは通常
- 24時間制の `H:mm`（例 `9:05`、`14:32`）。秒は出さない。分が変わったときだけ書き換える（毎秒の再描画をしない）
- 待機中（`タップで開始` の上）・計測中・まとめ表示中（`おつかれさま` の上）のどれでも一番上に出す
- 測位なしでも色は変えない
- 高速移動中（`高速移動中のため非表示` だけ）、初回の注意文の表示中、位置の権限がないときの表示には出さない
- 分が変わるときに量子演出を出さない。アプリの起動時の演出（`QuantumEffect.Startup`）だけは、左クラスタのほかの行と一緒にかける。歩行の開始とまとめの演出には含めない
- 左クラスタの縦の範囲は下0°〜下16°に広げてよい（上端を上げる。基準点の左22°・下8°と、水平の範囲は変えない）。目線（0°）より上には出さない

## 実装の方針

- 壁時計を注入できるようにする。今の `session/Clock`（`elapsedRealtime`）とは別に、現在時刻（`java.time` の `Instant` と端末のタイムゾーン）を返すものを用意し、`AppContainer` で本物を渡す。テストでは固定の時刻を渡す
- 分の境目まで待ってから更新する（例: 次の分の 0 秒までの残り時間だけ `delay` する）。ポーリングで毎秒更新しない
- 書式の関数は `ui/format` に置き、単体テストを書く
- 左パネルの高さが足りなければ、上に伸ばす（`HudPlacement` の左パネルの高さと中心を調整）。中央クリアゾーンとの距離（右端が左16°より外側）は今のまま守る
- 2D のフォールバック画面（`PhoneScreen`）にも時刻を出してよい（任意）

## 確認手順

1. `./gradlew test assembleDebug` が通る（JDK 21）
2. 単体テスト: `H:mm` の書式（`9:05`、`14:32`、`0:00`、`23:59`）。次の分の境目までの待ち時間の計算
3. Robolectric の表示テスト
   - 待機中・計測中（歩行中・停止中・測位なし）・まとめ表示中で、時刻が左クラスタの一番上にあること（ほかの行より上にあることを位置で確かめる）
   - 高速移動中、初回の注意文の表示中、位置の権限がないときに時刻が出ないこと
   - 測位なしでも時刻の色が `#B5D4F4` のままであること
   - 固定の時刻を進めると、分が変わったときに表示が変わること。秒が変わっただけでは再描画されないこと（再描画の回数を数えるか、書式の入力が分単位であることを確かめる）
   - 停止中（行が最も多い状態。住所2行と補助行あり）で、すべての行が左パネルの中に切れずに収まること。T11 の「下の行が切れない」テストがあれば、それに時刻の行を加えて通す
   - 左パネルの上端が目線（0°）より下、右端が左16°より外側にあること（`HudPlacementTest` に追加）
   - 量子演出: 起動時の演出に時刻の行が含まれること。歩行の開始・まとめの演出、分の更新では時刻の行に演出がかからないこと
4. 既存のテストがすべて通ること
5. **実機（adb）は使わない（インストールもしない）**
