# T12: 地図を常に北が上にする（2026-11-23 ユーザー要望）

まず [README.md](README.md) の共通ルールを読むこと。T1〜T11 は main に入っている。

## 目的

ユーザーの要望で、地図を heading-up（進行方向が上）から **north-up（常に北が上）** に変える。右下の地図（ミニマップ）と大きい地図の両方。

## 決定事項

- 地図のカメラの bearing は常に 0（北が上）。進行方向が変わっても地図は回さない
- 現在地の矢印は、進行方向（`WalkSessionState.mapBearingDeg`）へ回す。北が 0°、時計回り。矢印の向きは約300ms で滑らかに変える（359°→1° のような境目では短い方へ回す）
- 進行方向が分からない（`mapBearingDeg` が `null`）ときは、矢印の代わりに小さな丸（同じ色、矢印と同じくらいの大きさ）を出す
- 矢印と丸の色、大きさ、測位なしのときの色（`#888780`）は今のまま
- ピン、スタイル、ズーム、大きい地図の開閉は変えない

## 仕様書の更新（ユーザー要望。文言はこのとおり）

- `docs/UI.md` の heading-up の記述（§3.2 と §9 の大きい地図）を、north-up に直し、次の文を §3.2 に足す
  > 地図は常に北が上（north-up）。現在地の矢印が進行方向を向く。進行方向が分からないときは矢印の代わりに小さな丸を出す（2026-11-23 ユーザー要望）

## 自己診断と確認スクリプト

- 地図の自己診断（`AuraMap`）と `scripts/device-check.sh` の `map-replay`（`walk_stop` で曲がったときに bearing が約 90° 変わる）を、「カメラの bearing は常に 0 のまま、矢印の角度が約 90° 変わる」に直す。矢印の角度を `AuraMap` のログに出す

## 確認手順

1. `./gradlew test assembleDebug` が通る（JDK 21）
2. 単体テスト: カメラに渡す bearing が常に 0 であること。矢印の角度が `mapBearingDeg` に一致すること。359°→1° で短い方へ回ること。`null` のときは丸になること
3. T6a のエンドツーエンドテスト（`walk_stop` で `mapBearingDeg` が約 90° 変わる）はそのまま通ること
4. **実機（adb）は使わない（インストールもしない）**
