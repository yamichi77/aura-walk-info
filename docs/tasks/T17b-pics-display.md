# T17b: 信号機の情報の表示（2026-11-23 ユーザー承認・見た目は暫定）

まず [README.md](README.md) の共通ルールを読むこと。T1〜T16、T17a、T18a は main に入っている。追加機能の全体は [PLAN.md](../PLAN.md) §9、**安全ルールは §2.5（必読）**、表示の原則は [UI.md](../UI.md) §11。

## 目的

T17a の「表示してよいかの判定」が返した交差点の信号の状態を、HUD に出す。ユーザーの了承（2026-11-23）を受けて、**地図上の交差点の位置**と**左クラスタの補助行**に出す。空の方位帯の交差点の方向は T19b で作る。見た目は暫定で、受け入れでユーザーに確認する。**UI.md と PLAN.md は変更しない**（受け入れのあとでオーケストレーターが書き足す）。

## 表示の条件（T17a の判定のまま。ここで緩めない）

- 停止中、交差点から 30m 以内、信号の状態が 3 秒以内に届いている
- 高速移動中、初回の注意文の表示中、位置の権限がないときは出さない
- 判定が null になったら、今までの約 300ms のフェードで消す

## 左クラスタの補助行

- 判定が交差点を返している間、左クラスタの補助行（UI.md §3.1 の順 3）を信号の行に置き換える。停止中の `経過 21:05 ・ 15'05"/km` の代わりに出す
  - 待機中とまとめ表示中は、補助行が無いので、住所（待機中）またはヒント（まとめ表示中）の行のすぐ上に1行足す
- 文字列: `信号 ` のあとに、灯器の番号順に状態を `・` でつなぐ。例: `信号 赤7・青3`
  - 状態の書き方: 赤 → `赤`、青 → `青`、青の点滅 → `青点滅`。信号なし・制御の外・不明の灯器は書かない
  - 残り値が分かれば状態のすぐ後ろに数だけ付ける（単位は付けない。単位が確定していないため）。不明なら付けない
  - 書く灯器は最大 3 つ。4 つ目以降があれば末尾に `…`
  - 書ける灯器が1つもなければ `信号 情報なし`
- 色は**行全体で1色**: 新しい（1.5 秒未満）は `#9FE1CB`、古い（1.5〜3 秒）は `#888780`。状態ごとに色を変えない（青を目立たせないため）
- 14dp。幅が足りないときは今の `HudLabel` の横方向の縮小に任せる
- **アプリを起動してから最初に信号の行を出すときだけ**、最初の 6 秒は `信号は参考表示です` を同じ位置・同じ色で出してから、信号の行に切り替える

## 地図上の交差点の印

- ミニマップと大きい地図（2D と 3D）の、交差点の位置（T17a の電文の緯度経度）に印を出す
  - 細い円（直径は視角 1° 程度、線 1px 相当）。新しいときは `#E0F7FF` の 60%、古いときは `#888780`
  - 円の下に、灯器ごとの小さな点を横に並べる（最大 4 つ、すべて同じ大きさ）。赤 `#E07A7A`、青 `#7FBFA8`、青の点滅は `#7FBFA8` の輪郭だけ、それ以外は `#888780`。古いときはすべて `#888780`
  - 点滅や拡大などの動きは付けない
- 大きい地図では、円の右に左クラスタと同じ文字列（`信号 ` を除いた部分、例 `赤7・青3`）を 14dp で出す。ミニマップには文字を出さない
- 印は地図の座標に置く（傾けた 3D の地図でも正しい位置に来るようにする。maps-compose の `Marker` に描いたビットマップを使うなど、方法は任せる）
- 地図の外（円の外）にある交差点は出さない

## つなぎ込み

- T17a の状態の流れを、HUD の状態（`HudVisualSpec` など）に通す。既存の状態の作り方に合わせる
- デバッグ用の `PICS_REPLAY` で、実機でも表示を再現できるようにする（T17a で作った再生を使う）
- 自己診断のログ（例: `AuraPics`）に、表示した文字列と鮮度を出す（座標は出さない）。`scripts/device-check.sh` の `pics` のチェックに、表示の確認を足す（`bash -n` で文法だけ確かめる）

## 確認手順

1. `./gradlew test assembleDebug` が通る（JDK 21）
2. 単体テスト: 文字列の組み立て（例の各パターン、残り値なし、4 灯器以上、書ける灯器なし）
3. Robolectric の表示テスト
   - 停止中で判定が交差点を返すと、補助行が信号の行になる。歩行中や判定が null のときは出ない
   - 高速移動になったら、すぐに `高速移動中のため非表示` だけになる
   - 新しい → 古いで色が `#9FE1CB` → `#888780` に変わる。3 秒を超えたら消える
   - 起動後に最初に出すときだけ、6 秒間 `信号は参考表示です` が出る。2 回目以降は出ない
   - 待機中・まとめ表示中は、行が1行増えて出る
   - 停止中（住所 2 行）で、信号の行を含めてすべての行が左パネルに切れずに収まる
   - 大きい地図とミニマップに交差点の印が出る（ミニマップには文字なし、大きい地図には文字あり）
   - 状態ごとに文字の色が変わらない（青のときも赤のときも同じ色）
4. 既存のテストがすべて通る
5. **実機（adb）は使わない（インストールもしない）**
