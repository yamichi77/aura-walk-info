# T28: 候補を量子演出で出し、ルート全体を見てから案内を始める。屋外向けに量子演出を強める（2026-11-24 ユーザー要望）

まず [README.md](README.md) の共通ルールを読むこと。T1〜T27 は main に入っている。仕様は [UI.md](../UI.md) §9 の「目的地の候補とルート全体の表示」と §10 の「屋外での見え方」（オーケストレーターが更新済み。**UI.md は変更しない**）。

## 決定事項

### 1. 候補の出し方

- 候補を出すときは、大きい地図の不透明度を 40% に下げる（聞いている間の 30% はそのまま）
- 候補の行（名前と、距離・短い住所）を、量子演出（T13 の共通化した演出。点が集まって文字になる）で出す。演出のあとは今の表示。`やめる` の行も同じ

### 2. ルート全体の表示（ナビアプリのように、見てから開始）

- 候補を選ぶ（T27 の「長くつまんで目的地に」も同じ）と、経路を取得し、**すぐには案内を始めず**、ルート全体の表示にする
  - T18a の `NavRepository` に、経路を取ったが始めていない状態（例: `NavState.Preview`）と、`開始` で案内に進む操作、`やめる` で戻る操作を足す。経路の取得の回数と1日の上限は今のまま
- 地図の表示（2D でも 3D でも）:
  - 今の位置（スタート、小さな丸）、ゴール（ピン）、経路線を出す
  - 経路の全体が円に収まる縮尺・位置にカメラを合わせる（`LatLngBounds` と余白。3D でも北が上のまま）
  - 円の中の下の方に `約 15分・1.2km`（時間は分の切り上げ、距離は UI.md §4 の書き方）を出す
- 円の外の右側に、T22 の丸い量子ボタンで `開始`（アイコンは右向きの三角）と `やめる`（×）を出す。ルート全体の表示の間は、T27 の右側のボタン（`目的地`、`＋`、`－`、`現在地`、`3D`/`2D`）の代わりにこの2つを出す（位置と当たり判定の規則は T27 と同じ）
- `開始` で案内が始まり、地図は現在地の表示に戻る。`やめる` で候補の前（地図）に戻る
- ルート全体の表示中は、目的地の入力中と同じ扱い: 停止中なら閉じるカウントを止め、歩行中は 10 秒（T22・T27 の規則）。地図が閉じたら、ルート全体の表示をやめる（案内は始めない）。高速移動ではすぐに閉じる
- 表示に出す文と座標はログに出さない（今までどおり）

### 3. 屋外向けに量子演出を強める（UI.md §10）

- 演出の間だけ、点を大きく（今の約 1.5 倍）し、不透明度を 100% にする。演出が終わったら今までどおり
- 集まりきった瞬間に、円の縁（大きい地図の円と、丸いボタンの円）を約 0.2 秒、明るく光らせる（線を太く明るくして戻す。面は塗らない）
- 点の数の上限（パネルごとに 60 個）、出す場面と出さない場面、`QuantumEffectsEnabled` で無効にできることは変えない。高速移動では演出を打ち切ってすぐ消す（今までどおり）

## 確認手順

1. `./gradlew test assembleDebug` が通る（JDK 21）
2. 単体テスト: `NavState` の流れ（候補 → 経路の取得 → ルート全体 → 開始で案内 / やめるで戻る / 地図が閉じたら案内を始めない）、所要時間と距離の文字列、量子演出の点の大きさと不透明度（演出中と演出後）、縁の光の時間
3. Robolectric の表示テスト
   - 候補のとき地図が 40% になり、候補の行が点から現れる
   - 候補を選ぶと、案内は始まらず、スタート・ゴール・経路線と `約 ○分・○km`、`開始` / `やめる` が出る
   - `開始` で案内が始まり、右側のボタンが元に戻る。`やめる` で地図に戻る
   - ルート全体の表示中に地図が自動で閉じたら、案内が始まらない
   - 量子演出の間だけ点が大きく不透明度 100% で、集まりきったときに縁が光る。`QuantumEffectsEnabled = false` で演出なし
4. 既存のテストを合わせて直し、すべて通す
5. **実機（adb）は使わない（インストールもしない）**。main のワークツリーには触らない
