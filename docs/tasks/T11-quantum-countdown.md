## 2. 量子っぽい演出（決定事項）

アディティブ表示（黒は透明、明るいほど目立つ）なので、細い線と小さな点で描き、面を塗らない。色は `#7FDBFF`（シアン）と `#E0F7FF`、補助に `#9FE1CB`。演出は Compose の `Canvas` で描く。

1秒ごと（`3` → `2` → `1`）に、次の流れを繰り返す。

| 時間（各秒の中で） | 演出 |
|---|---|
| 0〜400ms「重ね合わせ → 収束」 | 約100個の小さな点（半径 1〜2dp 相当）が、ぼんやりした雲（確率の雲）の状態から、その秒の数字の形へ集まる。同時に、`3`・`2`・`1` の3つの数字の輪郭がうっすら重なって揺れて見え、正しい数字以外は薄れて消える（観測で1つに決まる感じ） |
| 400〜800ms「確定」 | 点が数字の形に並んだ状態で、ごくわずかに震える（量子のゆらぎ）。数字の輪郭がはっきり見える |
| 800〜1000ms「拡散」 | 点が外側へ散って薄れ、次の秒の雲になる |

- 数字の大きさは高さ約4°のまま
- 数字の周りに細い円（軌道）を1本描き、その上を小さな光点（電子）が1秒で1周する。残り時間の目安になる
- 0 になった瞬間: 開始なら、細い円が外へ広がって消える波紋を1回出す（約300ms）。終了も同じ
- 上の行（`開始` / `終了`）と下の行（`タップでキャンセル`）は今までどおり文字で出す
- 点の目標位置は、数字のグリフ（`3`・`2`・`1`）を描いた画像やパスから抜き出してよい。起動のたびに計算し直してよいが、カウントダウン中に重い処理をしない（目標位置は事前に計算しておく）
- 乱数はシードを固定できるようにし、テストでは決まった結果にする
- 60fps で動くこと。点の数は1か所の定数にまとめる
- 中央のパネルのクリックでキャンセル（T10 のまま）。高速移動中は出さない（T10 のまま）
- 画面の読み上げとテスト用に、数字は `contentDescription` か `testTag` で今の数字（`3` / `2` / `1`）を読めるようにする
