# T6b: 安全機能の仕上げ（注意文・タッチパッド・状態の切替の確認）

まず [README.md](README.md) の共通ルールを読むこと。T1〜T4 と T6a（合成ルートの再生・フィールドログ）は完了している。T5（ミニマップ）が別の作業ツリーで同時に進んでいる。

## 目的

PLAN.md §2.4 の安全機能を仕上げる。**高速移動時の非表示と中央クリアゾーンは、どんな操作でも上書きできないようにする。**

## 並行作業との分担

T5 が触るのは `ui/hud/MiniMapPanel.kt`（新規）、地図スタイルの JSON、`HudScene` の中の右クラスタを呼ぶ1か所、`scripts/device-check.sh` の地図の項目。このタスクでは右クラスタの中身と地図には触らない。`scripts/device-check.sh` に項目を足すときは、地図とは別の関数として足す。

## 実機の制約（T2・T4 の知見）

- グラスを装着していないと表示がスリープし、空間 UI は出ない。実機での見た目の確認は `scripts/device-check.sh` に項目を足し、オーケストレーターがユーザーの装着中に実行する
- 再生は `adb shell am broadcast -a io.github.yamichi77.aurawalkinfo.REPLAY -p io.github.yamichi77.aurawalkinfo --es scenario <walk_stop|fast|nofix|stop> --ef speed <倍率>`（T6a）

## 作るもの

### 1. 初回起動時の注意文（PLAN.md §2.4）

- 文言: 「徒歩専用。自転車・運転中は使用不可。横断歩道や駅のホームでは周囲を優先」
- 表示位置: **左クラスタの位置**（UI.md に位置の定めが無いので、オーケストレーターが決めた。中央クリアゾーンには出さない）。14dp、`#E0F7FF`、複数行でよい。表示中は左クラスタの数値の代わりに出す
- 初回起動時だけ出す。15秒たつか、タッチパッドの操作（下記）があったら消して、「表示済み」を保存する（T3 の `SafetyNotice`）
- 高速移動中は、注意文も含めて左クラスタの位置には `高速移動中のため非表示` だけを出す（高速移動が最優先）
- デバッグビルドでは `--ez resetNotice true` でもう一度出せるようにする
- Compose UI テストで、初回は出る・2回目は出ない・15秒で消える、を確かめる

### 2. タッチパッドでの表示・非表示の切替（任意）

- T2 の結果: パックのタッチパッドは `IQS9150`、Android のソースは `MOUSE | TOUCHPAD`。別に方向キーなどを出す仮想キーボード `uinput_nav` がある。実際のタップで何が届くかは未確認
- 次のどれかを受けたら HUD の表示・非表示を切り替える: source に `TOUCHPAD` か `MOUSE` を含む MotionEvent のタップ（DOWN → UP が 300ms 以内で移動が小さい）、または決定系のキー（`DPAD_CENTER`、`ENTER`、`BUTTON_A`）。連打で何度も切り替わらないよう 500ms の間引きを入れる
- ユーザーが非表示にしている間も、左クラスタの位置に小さく `HUD 非表示中` などは出さない（完全に消す）。ただし初回の注意文の表示中は、タップで注意文を閉じる動作を優先する
- **高速移動中の非表示は、タッチパッドの操作で表示に戻せないこと。** 単体テストで確かめる
- 受け付けたイベントと、切り替えた結果を logcat（タグ `AuraInput`）に出す

### 3. 状態の切替の確認

- T4 の `hudVisualSpecFor`（状態 → 見た目の仕様）と、T6a の再生を組み合わせたテストを書く: `fast` を流すと、`FAST` に入ったところでクラスタが非表示・`高速移動中のため非表示` が出る、抜けると戻る。ユーザーの非表示操作との組み合わせ（非表示操作をしていても `FAST` の表示は `高速移動中のため非表示` のまま、など）も確かめる
- `scripts/device-check.sh` に項目を足す: アプリを起動 → `fast` を `--ef speed 4` で再生 → `FAST` の間に左クラスタをキャプチャして、数値が消えて `高速移動中のため非表示` だけになっていることを確かめる（キャプチャ画像を保存し、logcat の `TRANSITION` と時刻を合わせて記録する）。`resetNotice` で注意文が出て15秒で消えることも確かめる

## 確認手順

1. `./gradlew test` と `./gradlew assembleDebug` が通る
2. 非装着でもできる確認（2D 表示でのキャプチャ、再生と logcat）を行う
3. 装着中なら `scripts/device-check.sh` を実行する。非装着なら、足した項目が「非装着」で正しく止まることまで確かめる

## 受け入れ条件

- 高速移動中の非表示は、タッチパッドの操作でも注意文でも解除されない（テストで確認）
- 初回の注意文が中央クリアゾーンの外に出て、2回目以降は出ない（テストで確認）
- `scripts/device-check.sh` に T6b の項目が入っている
