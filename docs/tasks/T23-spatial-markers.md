# T23: 曲がり角・目的地・信号機の上空に、空間に固定した印を置く（2026-11-24 ユーザー要望）

まず [README.md](README.md) の共通ルールを読むこと。T1〜T22 は main に入っている。**安全ルールは [PLAN.md](../PLAN.md) §2.5「空間に置く印」（必読）**、見た目は [UI.md](../UI.md) §11「空間に置く印」（どちらもオーケストレーターが更新済み。**変更しない**）。

## 目的

T20 の実機確認で、ユーザーから「せっかく 6DoF で空間に置けるから、ナビと信号はそれを生かしたい」と要望があった。頭に貼り付いた今の表示（右の案内の2行、左の信号の行、空の方位帯）は残し、現実の場所の上空に立体の印を足す。

## 作るもの

### 1. 位置の変換（純粋な Kotlin）

- 緯度経度（と地上からの高さ）を、ARCore の座標系の位置に変える
  - 基準: 今の GPS の位置と、そのときの ARCore の頭の位置（T15 の `HeadPoseSource`）
  - 向き: T15 の `HeadingEstimator` の北のずれ（オフセット）と、`HeadingAxes` の軸の取り方。T15・T19b と同じ定数を使う（別の定数を作らない）
  - 高さ: 地面の高さは「頭の高さ − 目の高さ 1.6m（定数）」とみなす
- 東西・南北の差は、短い距離（数百 m）向けの平面近似でよい
- GPS の測位が更新されるたびに置き直すと印が跳ねるので、新しい位置へ約 1 秒かけて滑らかに動かす。1m 未満の変化では動かさない
- 後で Geospatial（VPS）に切り替えられるよう、「緯度経度 → 空間の位置」を差し替えられるインターフェースにする（今回は GPS 版だけを作る）
- 単体テスト: 北・東・南・西の目標が正しい向きに置かれる、オフセットを変えると回る、高さ、滑らかな移動と 1m 未満の無視

### 2. 空間に固定した表示

- ARCore for Jetpack XR の Anchor と SceneCore（または Compose for XR）の仕組みで、印を現実の空間に固定する。どの API を使うかは、`gradle/libs.versions.toml` のバージョンのライブラリを調べて決め、選んだ理由を最終報告に書く。頭に追従する今の `Subspace(follow = ...)` とは別に置く
- 印は UI.md §11 の表のとおり（曲がり角の矢印、目的地の光の柱、信号機の印）。線だけで描き、面は塗らない。不透明度 50% 以下
- **仰角 5° 以上に見えている部分だけを描く。** 頭の位置から見た印の各部分の仰角を計算し、5° 未満の部分は描かない（印全体が 5° 未満なら出さない）
- 出す条件と消す条件は PLAN.md §2.5 のとおり
  - 曲がり角の矢印: 案内中で、曲がり角から 15m より遠いとき。矢印の向きは曲がった先の道の向き（T19a と同じ考え方）
  - 目的地の光の柱: 案内中で、目的地から 150m 以内のとき（定数）
  - 信号機の印: T17a の判定が交差点を返しているとき
  - 高速移動・追跡なし・北の推定なしか不確かさ 15° 超え・GPS の精度 20m より悪い・設定オフで消す。高速移動はすぐに、それ以外は約 300ms のフェード
- 設定: 「空間の印」のオン・オフを、T16 の設定の保存場所に足す（空の方位帯とは別）。初期値はオン。今回は HUD に切り替えの操作を置かず、デバッグ用の `SETTINGS` ブロードキャスト（例 `--ez spatial_marks false`）で切り替える
- 印の位置の更新は最大 2 Hz。頭の動きに合わせた描き直しは SceneCore に任せ、Compose の再構成を毎フレーム起こさない（電池のため）

### 3. デバッグと自己診断

- T19b の北の向きの上書き（`SETTINGS --ef north_offset ... --ef north_uncertainty ...`）、`NAV` の合成の経路、`PICS_REPLAY` で、実機で歩かずに印を出せるようにする
- ログ（例 `AuraSpatial`）に、各印の状態（出す / 消す とその理由）、頭からの距離、仰角の範囲を出す（座標と緯度経度は出さない）
- `scripts/device-check.sh` に `--only spatial` を足す。頭を正面に向けたまま見る前提にし、始める前と終わったあとに端末へ echo で「今から○秒、頭を正面に」「終わり」と出す。`bash -n` で文法だけ確かめる

## 確認手順

1. `./gradlew test assembleDebug` が通る（JDK 21）
2. 単体テスト: 位置の変換（上の項目）、仰角 5° の判定（印の一部だけ 5° 以上のとき、その部分だけ描く）、出す条件と消す条件のそれぞれ（15m、150m、30m、精度 20m、不確かさ 15°）
