# T21: 大きい地図の操作ボタンを円の外に枠つきで出す（2026-11-24 ユーザー承認）

まず [README.md](README.md) の共通ルールを読むこと。T1〜T19b は main に入っている。

## 目的

T20 の実機確認で、大きい地図の円の中に置いた `3D` / `2D`（T16）の文字が「地図上の表示と誤解する」とユーザーから指摘された。`目的地` / `ナビ終了`（T18b、円の上の端の内側）も同じ作り。操作ボタンを地図の円の外に出し、枠で囲んでボタンだと分かるようにする。仕様は [UI.md](../UI.md) §9 の「操作ボタン」（オーケストレーターが更新済み。**UI.md は変更しない**）。

## 決定事項

- 大きい地図（正面、下4°を中心に直径 28°）の円の**外の右側**に、2つのボタンを出す
  - `目的地`（案内中は `ナビ終了`、確認中は `もう一度でナビ終了`）: 円の右上の外。中心の目安は 右14°・上5°
  - `3D` / `2D`（切り替え先を出す）: 円の右下の外。中心の目安は 右14°・下13°
  - どちらも、ボタンの枠のいちばん円に近い点が、円の縁から 1° 以上離れていること。上下は表示できる範囲（上20°〜下20°）に収める
- 見た目: 文字 14dp、`#E0F7FF`。細い角丸の枠（1px 相当、`#E0F7FF` の 60%）。枠の内側は塗らない（黒＝透明）。不透明度は大きい地図と同じ（歩行中 70%、停止中 100%）
- つまむ当たり判定は、枠の外側まで含めて視角 3° 四方以上
- 円の中には操作の文字を出さない（今の `3D` / `2D` と `目的地` を円の中から取り除く）。候補の一覧・聞いている表示・エラーの文（T18b）は今までどおり円の中でよい（地図を 30% に暗くして出すため）
- ボタンは大きい地図と一緒に出し入れする（開閉のフェードと量子演出（UI.md §10）も大きい地図に合わせる）。高速移動ではすぐに消す
- 地図の外のタップで大きい地図を閉じる仕組み（視野全体の透明なパネル）より手前にボタンを置き、ボタンのタップで地図が閉じないようにする
- 3D の地図の中身、自動で閉じる時刻の規則、音声入力の流れは変えない
- ボタンは `HudPlacement` で角度から置く（新しい空間パネルとしてよい）

## 確認手順

1. `./gradlew test assembleDebug` が通る（JDK 21）
2. 配置のテスト（`HudPlacementTest` に追加）: 2つのボタンの枠が円の縁から 1° 以上外にあり、表示できる範囲に収まること
3. Robolectric の表示テスト
   - 大きい地図を開くと、円の外に `目的地` と `3D`（2D 表示のとき）/ `2D`（3D 表示のとき）が枠つきで出る。円の中に操作の文字が無い
   - ボタンのタップで切り替え・音声入力が動き、大きい地図は閉じない。地図の円のタップと、地図とボタン以外のタップでは今までどおり閉じる
   - 案内中は `ナビ終了`、確認中は `もう一度でナビ終了` になる
   - 大きい地図を閉じるとボタンも消える。高速移動ではすぐに消える
4. T16・T18b の既存のテストを、ボタンの場所の変更に合わせて直し、すべて通す
5. **実機（adb）は使わない（インストールもしない）**。オーケストレーターが受け入れ中なので、main のワークツリーには触らない
