# T16: 大きい地図の 3D 表示の切り替え（2026-11-23 ユーザー承認）

まず [README.md](README.md) の共通ルールを読むこと。T1〜T15、T17a、T18a は main に入っている。追加機能の全体は [PLAN.md](../PLAN.md) §9、安全ルールは §2.5。

## 目的

大きい地図（UI.md §9）に 3D 表示のオプションを付ける。仕様は [UI.md](../UI.md) §9 の「3D 表示のオプション」（**UI.md は変更しない**）。

## 決定事項

- 大きい地図の円の**下の端の内側**に、小さく `3D` または `2D` を出す（今の表示と逆の、切り替え先を出す。例: 2D 表示のときは `3D`）。14dp、`#E0F7FF`、不透明度は大きい地図と同じ
- その文字をつまむ（タップ）と切り替わる。文字の周りに、つまみやすい大きさ（視角 3° 四方程度）の当たり判定を取る。文字以外の地図の上のタップは、今までどおり大きい地図を閉じる
- 選んだ方を端末に覚えておき（`SharedPreferences` などのアプリ専用の保存。設定の保存場所を1か所にまとめる）、次に開くときとアプリの再起動後も使う。初期値は 2D
- 3D のとき
  - カメラの傾き（tilt）は 60°。北が上のまま（bearing 0）。ズームは 17.5（建物が立体で出るズーム）
  - 建物を立体で出す（`isBuildingEnabled = true`）
  - 建物は暗い灰色にする。大きい地図用の 3D のスタイル（例: `map_style_dark_bigmap_3d.json`）を作り、建物（`landscape.man_made`）の塗りを `#141414`、線を `#2A2A2A` 程度にする。そのほかは今の大きい地図のスタイルと同じ
  - 傾けると地図の中心が見かけ上ずれるので、現在地の矢印（または丸）が円の中心に来るように、カメラの target と padding を調整する。矢印の見かけの大きさは 2D と同じ
- 2D は今のまま（tilt 0、ズーム 16.5、建物なし）
- 切り替えたときは、カメラを約 500ms のアニメーションで動かす。量子演出（UI.md §10）は出さない（自分の操作だが、地図の中身の切り替えであり、開閉ではないため）
- 開ける条件・自動で閉じる時間・位置・大きさ・高速移動での即時の非表示は今のまま。切り替えをタップしても、自動で閉じる時刻は延ばさない
- ミニマップ（右下）は 2D のまま変えない
- 傾き・ズーム・建物の色は定数1か所にまとめる（受け入れで実機を見て調整するため）

## 自己診断（デバッグビルド）

- 地図の自己診断（`AuraMap`）に 3D の項目を足す: 要求した tilt と、実際にカメラが受け入れた tilt（SDK はズームによって tilt の上限を下げることがある）、地図の読み込みまでの秒数、スナップショットの非黒画素率・平均輝度・最大輝度（円の内側）
- `--es mode map3d` で、大きい地図の大きさの空間パネルに、(tilt 0, ズーム 16.5)、(45, 17)、(60, 17.5)、(67.5, 17.5) を 8 秒ずつ順に出し、それぞれの結果を `AuraMap` に出し、スナップショットの PNG をアプリ専用領域に保存する。API キーがないときは `SKIP`
- `scripts/device-check.sh` に `--only map3d` を足す（起動、ログの採取、PNG の取り出し、判定）。今は実機で動かせないので `bash -n` で文法だけ確かめる
- `docs/device-capabilities.md` に「大きい地図の 3D（T16、受け入れで実行）」の節を足し、手順を書く。結果の欄は空けておく

## 確認手順

1. `./gradlew test assembleDebug` が通る（JDK 21）
2. 単体テスト: 3D と 2D のカメラの値（tilt、ズーム、bearing が 0）、3D のときに建物が有効になること、設定の保存と読み込み（初期値は 2D）
3. Robolectric の表示テスト
   - 大きい地図に `3D`（2D 表示のとき）/ `2D`（3D 表示のとき）が出る
   - 切り替えの文字のタップで表示が切り替わり、大きい地図は閉じない
   - 切り替えの文字以外の地図のタップでは、今までどおり閉じる
   - 切り替えても自動で閉じる時刻が変わらない
   - 高速移動になったら、3D でもすぐに閉じる
   - 切り替えた設定が、閉じて開き直しても残る
   - ミニマップは 3D にならない
   - 3D のスタイルのファイルで、建物の色が暗い（`MapStyleTest` にならって、輝度が一定以下であることを確かめる）
4. `bash -n scripts/device-check.sh` が通る
5. 既存のテストがすべて通る
6. **実機（adb）は使わない（インストールもしない）**
