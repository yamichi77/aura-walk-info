# T27: 大きい地図を操作できるようにし、操作のたびに閉じるカウントを数え直す（2026-11-24 ユーザー要望）

まず [README.md](README.md) の共通ルールを読むこと。T1〜T26 は main に入っている。仕様は [UI.md](../UI.md) §9 の「手動で閉じる」「操作するたびにカウントを数え直す」「地図の操作」（オーケストレーターが更新済み。**UI.md は変更しない**）。T28（候補とルート全体の表示）は、このタスクのあとに同じ場所を触る。

## 決定事項

1. **地図の上のタップでは閉じない。** 閉じるのは地図の外のタップ（今の視野全体の透明なパネル）と自動で閉じるときだけ。今の「地図をタップしたら閉じる」（`HudTarget.BIGMAP` のタップ）をやめる
2. **つまんで動かす:** 大きい地図の上でつまんだまま動かすと、地図が動く（`CameraUpdateFactory.scrollBy` などで、指の動きの画素をカメラの移動に変える。北が上のまま。3D でも同じ）。ハンドトラッキングのつまむ操作が Compose のドラッグとして届くかは実機で確かめる前提にし、ドラッグの検出は Compose の標準（`detectDragGestures` など）で作る
   - 動かしたあとは、現在地に戻るまでその場所を表示し続ける（現在地の更新でカメラを戻さない）。大きい地図を開き直すと現在地に戻る
   - 現在地の矢印（または丸）は、地図を動かしたら、円の中心ではなく地図上の現在地の位置に出す（画面外なら出さない）
3. **ボタン:** 円の外の右側に、T22 の丸い量子ボタンで `＋`（拡大、ズーム +1）、`－`（縮小、ズーム −1）、`現在地`（現在地に戻る）を足す。右側に縦に並べる（上から `目的地`、`＋`、`－`、`現在地`、`3D` / `2D`）。各ボタンの当たり判定は視角 3° 四方以上、円の縁から 1° 以上離し、上下は表示できる範囲（上20°〜下20°）に収める。ズームの範囲は 2D で 14〜19、3D で 16〜20（定数）
   - アイコンは線で描く: `＋` と `－` は記号、`現在地` は円と十字（照準）
4. **長くつまんで目的地に:** 地図の上の場所を約 0.8 秒つまみ続けると、その場所を目的地の候補にする。名前は `android.location.Geocoder` の逆ジオコーディングで付け（今の住所の整形の関数を使ってよい）、取れなければ `地図で選んだ場所`。候補を1件だけ選んだのと同じ扱いで T18a の経路の取得に進む（T28 でルート全体の表示が間に入る）
5. **操作のたびにカウントを数え直す:** 地図を動かす、拡大縮小、現在地に戻る、3D/2D の切り替え、目的地の操作（ボタン・候補・長くつまむ）のたびに、閉じる時刻を「その時点から、停止中なら 30 秒、それ以外なら 10 秒後」にする（`BigMapControl`）。T22 の「停止中の入力中はカウントを止める」と「入力中に歩行中になったら 10 秒」はそのまま。高速移動ではすぐに閉じる
6. **右クラスタを隠す:** 大きい地図を開いている間は、右クラスタ（ミニマップ、案内の2行、視界の端の矢印）を出さない（ミニマップは今も隠している）

## 確認手順

1. `./gradlew test assembleDebug` が通る（JDK 21）
2. 単体テスト: 閉じる時刻の数え直し（各操作で停止中 30 秒・歩行中 10 秒に戻る、高速移動ですぐ閉じる、入力中の停止は今のまま）、ドラッグの画素からカメラの移動への変換、ズームの範囲
3. Robolectric の表示テスト
   - 地図の上のタップで閉じない。地図の外のタップで閉じる
   - 右側に5つの丸いボタンが縦に並ぶ（配置のテストを `HudPlacementTest` に追加: 円の縁から 1° 以上、表示できる範囲の中）
   - `＋` / `－` でズームが変わり、範囲の端で止まる。`現在地` で現在地に戻る
   - ドラッグで地図が動き、そのあと現在地が更新されても戻らない。開き直すと戻る
   - 長くつまむと、その場所で経路の取得が始まる（通信は偽物に差し替える）
   - 大きい地図を開いている間、右クラスタの案内の2行と矢印が出ない
4. 既存のテストを合わせて直し、すべて通す
5. **実機（adb）は使わない（インストールもしない）**。main のワークツリーには触らない
