# T13: 操作したときの量子演出を HUD 全体に広げる（2026-11-23 ユーザー要望）

まず [README.md](README.md) の共通ルールを読むこと。T1〜T12 は main に入っている。T11 の量子カウントダウン（`QuantumCountdownMotion.kt`、`QuantumCountdownDigit.kt`、`CountdownPanel.kt`）は、装着して「よさそう」と好評だった。

## 目的

T11 と同じ量子っぽい演出（点が雲から集まって形になり、今の表示に落ち着く）を、**ユーザーが自分で操作したときとアプリの起動時だけ**、HUD のほかの場面にも使う。演出が終わったら、今までどおりの表示になる。

## 決定事項（出す場面と出さない場面）

### 出す場面（どれも 0.5 秒ほどで終わる）

| 場面 | 演出 |
|---|---|
| 歩行の開始（カウントダウンの波紋の直後） | 左クラスタの距離と時間が、点の雲から文字の形に集まって現れる。集まりきったら本物の文字に切り替わる |
| 終了のまとめ（終了のカウントダウンの直後） | 左クラスタの `おつかれさま` とまとめの数字が、同じように点から現れる |
| 大きい地図を開く | 点が集まって円（直径 28°）の輪郭になり、そこへ地図がフェードインする |
| 大きい地図を閉じる（タップでも自動でも） | 大きい地図の点が外へ散って消え、右下のミニマップが点から集まって現れる |
| アプリの起動（HUD が最初に出るとき1回だけ） | 左クラスタとミニマップが点から現れる。初回の注意文が出ているときは、注意文には演出をかけない |

### 出さない場面（今のまま）

- 距離・時間など、数字が更新されるとき（毎秒変わるため。目のちらつき、電池、発熱）
- 歩行中・停止中・測位なしの自動の切り替え（自分の操作ではないため。今の約300ms のフェードのまま）
- 高速移動で HUD を消すとき（安全のため即座に消す）。演出の途中で高速移動になったら、演出を打ち切って即座に消す
- 初回の注意文

### 見た目

- T11 と同じ色（`#7FDBFF`、`#E0F7FF`、補助に `#9FE1CB`）。細い線と小さな点だけで描き、面を塗らない
- 点の数はパネルごとに 60 個以下。明るくなりすぎないよう、点の不透明度は 70% 以下
- 文字の形への集まり方は、T11 のグリフから点を抜き出す方法を共通化して使う（文字列でも使えるようにする）。目標位置は演出の前に計算しておき、演出中に重い処理をしない
- 本物の表示への切り替えは、最後の約150ms で本物の表示をフェードインし、点をフェードアウトする

### 共通化と切り替え

- T11 の演出の計算（雲 → 収束 → ゆらぎ → 拡散）を、カウントダウン以外でも使えるように共通化する。カウントダウンの見た目は変えない
- 量子演出をまとめて無効にできる定数を1か所に置く（例: `QuantumEffectsEnabled = true`）。無効のときは今までの表示（フェード）になる

## 確認手順

1. `./gradlew test assembleDebug` が通る（JDK 21）
2. 単体テスト: 共通化した演出の計算（各時間での点の位置、収束後に目標に近いこと、拡散で外へ動くこと）。T11 のカウントダウンのテストはそのまま通ること
3. Robolectric の表示テスト
   - 演出が終わった後の左クラスタ・まとめ・大きい地図・ミニマップの表示が、演出なしのときと同じ文字列・状態になること
   - 距離や時間が更新されても演出が始まらないこと
   - 移動状態が自動で変わっても演出が始まらないこと
   - 演出の途中で高速移動になったら、すぐに `高速移動中のため非表示` だけになること
   - `QuantumEffectsEnabled = false` で今までどおりの表示になること
4. **実機（adb）は使わない（インストールもしない）**
